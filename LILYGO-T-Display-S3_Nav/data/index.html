OTA 更新

韌體更新（firmware.bin）

從 Arduino IDE 匯出二進位檔：草稿碼 → 匯出已編譯的二進位檔，或使用 arduino-cli 產生的 .bin。

網頁檔案（spiffs.bin）

包含 index.html / style.css / app.js。更新完成後裝置會自動重新啟動。

注意事項

  • 更新期間請勿斷電，裝置會在完成後自動重新啟動。
  • 韌體分割表必須為 3MB APP x2 + 9.375MB SPIFFS，否則 OTA 會失敗。
  • SPIFFS 更新會先卸載檔案系統，上傳期間網頁可能暫時無法開啟，屬正常現象。
  • 若更新後無法連線，請以 USB 重新燒錄並重新上傳 data/。
